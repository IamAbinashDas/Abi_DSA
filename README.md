# 📘 Abi_DSA

## 📌 Overview
The **Abi_DSA** repository is a curated collection of **Data Structures and Algorithms (DSA)** implemented in **Java**. It is designed to help learners strengthen their coding fundamentals, prepare for interviews, and practice problem-solving.

---

## ✨ Features
- 🔹 Implementations of core **data structures**: arrays, strings, linked lists, stacks, queues, trees, graphs  
- 🔹 Classic **algorithms**: sorting, searching, recursion, dynamic programming, greedy, backtracking  
- 🔹 **Pattern programs** for Java (stars, numbers, pyramids, etc.)  
- 🔹 Beginner-friendly examples with clean, modular code  
- 🔹 Useful for **coding interview preparation** and academic practice  

---

## 🛠️ Tech Stack
- **Java (JDK 8+)**  
- GitHub for version control & collaboration  

---

## 🚀 Getting Started
1. Clone the repository:  
   ```bash
   git clone https://github.com/IamAbinashDas/Abi_DSA.git
   ```
2. Navigate to the desired folder (e.g., `Arrays`, `Graphs`, `Patterns`)  
3. Compile and run:  
   ```bash
   javac filename.java
   java filename
   ```
